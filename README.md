# 练手项目总说明

这套“练手项目”是为你投递开发实习准备的作品集素材。它们**不是让你直接照抄进简历就完事**，而是需要你先运行、再读懂、最后能讲清楚，面试时才经得起追问。

## 三个项目

| 目录 | 项目 | 主要技术 | 建议学习用时 |
|---|---|---|---|
| `01-java-book-manager` | 图书管理系统 | Java SE + JDBC + MySQL | 2-3 天 |
| `02-python-video-organizer` | 视频素材整理助手 | Python（标准库） | 半天-1 天 |
| `03-html5-ordering-demo` | 点餐页面演示 | HTML / CSS / JavaScript | 半天-1 天 |

## 建议顺序

1. **先跑 Python**：只需要安装 Python，零依赖，最快建立“我能跑通一个项目”的信心；
2. **再打开 HTML5**：双击 `index.html`，边点边看代码；
3. **最后攻 Java**：需要装 JDK + MySQL，花时间最长，但它最能体现你的 Java 功底。

## 面试前检查清单

对每个项目，你都要能做到：

- [ ] 能在自己电脑上从零运行一遍（不是只看别人跑）；
- [ ] 能不看文档说出项目有哪些功能、数据怎么存；
- [ ] 能指出代码里自己改过的一处细节；
- [ ] 能说出下一步想怎么升级；
- [ ] 能解释为什么用 AI 辅助是合理的（先自己搭结构、让 AI 帮忙补细节和查错，而不是把需求整段丢给 AI）。

> 重要提醒：投递前请把项目代码放到自己的 GitHub 仓库，并在简历里只写“个人练习项目 / 课程项目”，不要写“商业项目”或编造团队规模。

## 上传到 GitHub（自己动手一次即可）

1. 在 GitHub 网站右上角 `+` → `New repository`，仓库名建议写 `practice-projects`，选择 Public，不要勾选任何初始化选项；
2. 回到本目录，在命令行依次执行（把 `<你的用户名>` 换成你的 GitHub 用户名）：

```bash
git remote add origin https://github.com/<你的用户名>/practice-projects.git
git push -u origin main
```

3. 如果提示登录，按浏览器提示完成 GitHub 登录授权即可；
4. 上传成功后，把仓库地址（如 `https://github.com/<你的用户名>/practice-projects`）发给招聘方，或写进简历中“代码可提供”的位置。

> 建议：每次上传前先运行一遍项目，确认能跑再提交；Git 只会记录你确认过的内容。
