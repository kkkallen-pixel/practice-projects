# 03 HTML5 点餐页面演示

一个纯 HTML + CSS + JavaScript 的“轻食餐厅点餐页”，不用安装任何东西。
双击打开 `index.html` 就能在浏览器里运行。

## 已实现功能

- 菜品卡片展示（数据集中放在 `js/app.js`，方便以后接后端接口）；
- 按分类筛选（全部 / 主食 / 小吃 / 饮品 / 甜点）；
- 关键词搜索；
- 加入购物车、修改数量、删除商品；
- 购物车自动计算总价；
- 使用 localStorage 保存购物车，刷新页面不丢失；
- 移动端自适应布局。

## 你可以怎么讲

面试时介绍：*“我自己搭过网页结构。这个练习里我把数据、结构、样式和交互分开，用数组管理菜品数据，再按条件渲染；购物车用 localStorage 持久化，为以后接后端接口留好了位置。”*
