# 02 Python 视频素材整理助手

这是一个用 **Python 标准库** 编写的命令行小工具，模拟“机器人动作视频素材”的整理场景。
它能把一份杂乱的动作拍摄记录表，清洗成一份可直接使用的清单，并打印统计结果。

## 运行方法（Windows）

1. 安装 Python 3.9 或更高版本（课程环境一般已安装）。
2. 在本目录打开命令行，运行：

```bash
python organize_videos.py --input sample_input.csv --output 整理结果.csv
```

3. 打开生成的 `整理结果.csv`，并查看命令行里的统计信息。

## 它做了什么

- 读取 CSV（自动兼容 UTF-8 BOM）；
- 校验必填字段（日期、任务编号、动作名称、拍摄序号）；
- 自动生成建议文件名，例如 `20260715_A001_站立挥手_003.mp4`；
- 去掉重复记录，并在结果中保留首条；
- 在命令行输出“有效记录数、重复数、按任务/动作统计”等信息。
